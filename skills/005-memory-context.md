# Memory & Context

## Purpose

The Memory & Context skill establishes how the Universal AI Operating Layer preserves, retrieves, prioritises, and applies contextual information throughout reasoning, decision-making, and workflow execution.

Its purpose is to ensure that AI responses remain coherent, relevant, and consistent by maintaining the appropriate context across interactions while respecting governance and human oversight.

Memory & Context transforms stored knowledge into situational intelligence.

---

# Scope

The Memory & Context skill applies to every interaction requiring contextual understanding, including conversations, workflows, projects, organisational knowledge, historical decisions, and user-defined objectives.

It is independent of any specific AI model and provides a common context management framework for all industries and applications.

---

# Core Principle

Intelligence depends not only on what is known, but also on what is relevant at the moment of reasoning.

Context determines the appropriate application of knowledge.

---

# Operating Objectives

The Memory & Context skill exists to:

- preserve contextual continuity
- retrieve relevant information efficiently
- prioritise meaningful context
- distinguish temporary from persistent memory
- minimise unnecessary information
- support consistent reasoning
- improve workflow continuity
- strengthen organisational intelligence

---

# Context Classification

Context should be classified according to its intended lifespan.

Typical classifications include:

- transient context
- session context
- workflow context
- project context
- organisational context
- persistent context

Classification determines how long context should remain available.

---

# Context Retrieval

Only context relevant to the current objective should be retrieved.

Retrieval should prioritise:

- relevance
- recency
- reliability
- continuity
- objective alignment

Retrieval should minimise unnecessary information while preserving essential understanding.

---

# Context Prioritisation

When multiple contextual sources exist, priority should generally favour:

- current objective
- active workflow
- organisational policies
- historical decisions
- supporting reference material

Priority should remain transparent and explainable.

---

# Context Application

Retrieved context should support reasoning rather than constrain it.

Context should:

- improve continuity
- preserve consistency
- reduce repetition
- support informed recommendations
- acknowledge uncertainty where appropriate

Context should enhance judgement, not replace analytical reasoning.

---

# Context Evolution

Context changes over time.

The Memory & Context skill should:

- update evolving information
- retire obsolete context
- preserve significant history
- maintain contextual consistency
- avoid conflicting context

Context should evolve without compromising organisational integrity.

# Context Governance

Memory & Context operates under governance principles established by Knowledge Management.

Governance includes:

- review requirements
- correction mechanisms
- retirement procedures
- human approval where appropriate

# Human Oversight

Human stakeholders remain responsible for approving significant persistent memory changes.

- correct contextual information
- remove obsolete context
- approve persistent updates

Human governance remains authoritative.

# Capability Boundary

Memory & Context is responsible for:

- preserving contextual continuity
- retrieving relevant context
- maintaining contextual consistency
- supporting reasoning with context
- managing context lifecycle

Memory & Context is not responsible for:

- governing organisational knowledge
- performing analytical reasoning
- selecting experts
- executing workflows
- replacing human oversight

Its responsibility is maintaining trustworthy contextual intelligence.
