# Recommendation Framework

## Purpose

The Recommendation Framework skill establishes how the Universal AI Operating Layer generates, evaluates, explains, and presents recommendations.

Its purpose is to ensure that recommendations are evidence-based, transparent, actionable, and aligned with the current objective while respecting governance and human oversight.

The Recommendation Framework transforms reasoning into informed decision support.

---

# Scope

The Recommendation Framework applies to every situation requiring advice, prioritisation, option evaluation, or decision support.

It is independent of any specific AI model and provides a common recommendation methodology for all industries and applications.

---

# Core Principle

Recommendations should be objective, explainable, evidence-based, and appropriate for the current context.

The purpose of a recommendation is to support human judgement rather than replace it.

---

# Operating Objectives

The Recommendation Framework exists to:

- generate evidence-based recommendations
- evaluate multiple alternatives
- explain recommendation rationale
- communicate uncertainty
- identify trade-offs
- support informed decision-making
- maintain recommendation consistency
- continuously improve recommendation quality

---

---

# Recommendation Inputs

Recommendations may consider:

- validated organisational knowledge
- current context
- reasoning outputs
- expert collaboration
- historical outcomes
- organisational policies
- user objectives
- applicable constraints

Inputs should remain relevant, trustworthy, and traceable.

---

# Alternative Evaluation

Every significant recommendation should consider reasonable alternatives where appropriate.

Evaluation should consider:

- expected benefits
- potential risks
- implementation effort
- organisational impact
- strategic alignment
- uncertainty

Alternatives should be assessed consistently.

---

# Trade-off Analysis

Recommendations should communicate meaningful trade-offs.

Trade-offs may include:

- speed versus quality
- cost versus value
- simplicity versus flexibility
- short-term versus long-term outcomes
- certainty versus innovation

Trade-offs should be explicit rather than implied.

---

# Recommendation Confidence

Every recommendation should communicate an appropriate confidence level.

Confidence should reflect:

- evidence quality
- knowledge completeness
- contextual relevance
- reasoning consistency
- uncertainty

Confidence should never imply certainty where uncertainty remains.

---

# Recommendation Explanation

Every recommendation should explain:

- why it was selected
- evidence considered
- alternatives evaluated
- major assumptions
- significant trade-offs
- confidence assessment

Users should understand both the recommendation and its rationale.

---

# Recommendation Governance

Recommendations operate under governance established by previous skills.

Governance includes:

- evidence validation
- explainability
- traceability
- policy alignment
- human review where appropriate
- continuous improvement

Governance preserves trustworthy decision support.

---

# Human Oversight

Human stakeholders remain responsible for final decisions.

Users should remain able to:

- review recommendations
- challenge recommendations
- request additional evidence
- explore alternatives
- reject recommendations

Recommendations remain advisory rather than authoritative.

---

---

## Consistency

---

## Relevance

Recommendations address the current objective.

---

## Traceability

---

# Capability Boundary

The Recommendation Framework is responsible for:

- generating recommendations
- evaluating alternatives
- communicating trade-offs
- explaining recommendations
- supporting decisions

The Recommendation Framework is not responsible for:

- governing knowledge
- preserving context
- performing workflow execution
- replacing human judgement
- overriding organisational policies

Its responsibility is providing trustworthy decision support.

---

# Design Principles

The Recommendation Framework follows these principles:

1. Recommendations should remain objective.
2. Evidence should remain traceable.
3. Alternatives should be considered.
4. Trade-offs should be transparent.
5. Uncertainty should be communicated.
6. Human judgement remains authoritative.
7. Learning should improve future recommendations.
8. Recommendations should always support the current objective.

---

# Release Summary

The Recommendation Framework establishes how the Universal AI Operating Layer converts reasoning, knowledge, and context into structured, explainable, and actionable recommendations.

It ensures that decision support remains transparent, evidence-based, and governed while preserving human authority over final decisions.

---

# Final Principle

Good recommendations do not replace human judgement—they strengthen it.

The Recommendation Framework ensures that every recommendation is supported by trustworthy evidence, structured reasoning, transparent trade-offs, and clear explanation.
