# System Glossary

Definitions of core terms utilized within the Thought Leadership Operating System (TLOS).

---

### Atomic Insight
A single, self-contained thought or thesis point stored in `/knowledge`. It is decoupled from formatting or publication channel.

### Context Packing
The process of combining selected files from `/knowledge` and `/research` into an LLM context window to inform a specific generation task.

### Founder Signal
The distinct tone, technical depth, unique insight, and perspective that characterizes an executive's authentic voice.

### Skill Primitive
An executable, highly structured prompt specification residing in `/skills` that instructs an LLM how to transform raw knowledge into a specific deliverable.

### Thought Artifact
A completed, formatted deliverable (e.g., Essay, Op-Ed, Whitepaper, Presentation) ready for human audit and publication.
